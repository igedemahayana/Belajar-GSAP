# Materi GSAP yang sudah saya pelajari:

### Method Dasar GSAP

- gsap.to()
- gsap.from()
- gsap.fromTo()

### Properti Animasi

- x
- y
- xPercent
- yPercent
- scale
- scaleX
- scaleY
- skewX
- skewY
- rotation
- opacity
- transformOrigin

### Waktu & Easing

- duration
- delay
- ease (.out, .in, .inOut)
- repeat -> dimulai dari index 0, jadi kalau masukin 1 repeat nya 2x
- yoyo
- stagger

### Targeting cara GSAP menunjuk element

- Menghubungkan GSAP dengan ID
- Menghubungkan GSAP dengan variabel yang dibuat
- Menghubungkan GSAP lebih dari satu element sebagai target
